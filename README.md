# Osteria Rosso

This is a standalone restaurant menu made with one HTML file. It does not need Node.js, npm, installed packages, a backend, or separate JavaScript files.

## Run locally

Open `index.html` in a browser. Menu filters, the cart, sample orders, invoices, rewards, and the staff demo work in that browser and are saved in its local storage. Browser storage may behave differently for local files; hosting the folder as a static website is recommended for persistent use.

The staff dashboard is only a local demo, not secure and not shared with other devices. Its demo code is `4040`. Do not use it to manage real orders or customer data.

## Create a menu QR code

Open the **Scan for the menu** section. When the website is hosted, its address is filled in automatically; choose **Create QR code** to generate a QR code for that address. When running `index.html` from your computer, paste the public website address first. QR image generation uses an online QR service and needs an internet connection.

The website's fonts and food photos also load from online services.
